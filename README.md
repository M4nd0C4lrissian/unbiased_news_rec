# Constructing Political Coordinates

Except for the following files:

- collaborative_filtering.py
- oracle.py
- rand_content.py
- sim_functions.py 
- user_choice.py
- user generation.py

All of which came from this repository: https://github.com/IIT-ML/WWW21-FilterBubble/tree/main/src/simulation, sourced by the paper cited below.

The rest of the code was generated by us, and the data used can be found below.

The codebase is relatively fragmented at the moment, but we will point you to the high level flow for behavior:

There are ipynb files to generate bert embeddings:

- data_generation.ipynb
- BertEmbeddings.ipynb

Then we have the Disentangler training:

- training.py

We then generate landmark embeddings and construct CPC:

- create_landmarks.py
- create_nearest_neighbors.py (or baseline_correlation_matrix.py for already generated interaction data)

We then train our GCFs:

- either per_user_GCF or baseline_per_user_GCF (which allows various configurations, but has to be altered manually)

Evaluation is very fragmented for the time being, though the main behavior can be seen in:

- get_eval_data.py

The original dataset can be found here:

[Data is here.](https://www.dropbox.com/scl/fo/31bvt18zjkql2zorltx6k/AHRjtozu_8w_xuixWmRkv88?rlkey=w5bg63wi551trq6trwsjqrxwc&st=fhbbaf5m&dl=0)
